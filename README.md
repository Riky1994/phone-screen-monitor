# 手机性能看板 PhoneDeck

把一台闲置手机变成电脑旁边的实时性能监控屏。手机上**不用装任何 App**，打开浏览器就是看板。

- 实时数据：CPU 总占用 / 每核占用、内存、显卡（占用 / 温度 / 显存 / 功耗 / 频率）、磁盘、磁盘读写速度、网络上下行、进程 TOP
- 1 秒刷新，自带 2 分钟趋势曲线
- 深色 UI，手机竖屏一屏显示，适配 iPhone / Android / 平板 / 墨水屏
- 全部本地局域网通信，不联网、不上传任何数据

---

## 一、三步开始

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 双击 **`允许手机访问.bat`** | 会弹 UAC，点「是」。只为 8787-8796 这一段端口开入站规则，**只需做一次** |
| 2 | 双击 **`启动看板.bat`** | 服务在后台启动，电脑浏览器会自动打开看板 |
| 3 | 手机连**同一个 Wi-Fi**，浏览器打开 `http://192.168.1.85:8787` | 也可以直接用手机相机扫根目录的 `qr.png` |

试一下：手机上能看到 CPU / 显卡数字在跳，就成功了。

> 电脑走的是网线（192.168.1.85），手机只要连同一个路由器的 Wi-Fi 就行，不要求同一网线口。
> 如果以后 IP 变了（路由器重新分配），重开一次 `启动看板.bat`，`address.txt` 和二维码会更新。

### 建议再花 30 秒做的事

双击 **`安装开机自启.bat`**：以后每次开机登录，服务都会自己在后台启动，不用再点。

## 二、手机端调校（重要）

一块"监控屏"要一直亮着才好看，手机默认会自动锁屏：

- **横竖屏切换**：看板右上角有个 `自动 / 横屏 / 竖屏` 按钮，点一下切一档，选择会记住：
  - **自动**：跟着手机重力感应走（推荐）
  - **横屏**：强制按横屏排版。如果手机锁定了竖屏（或浏览器不跟随旋转），画面会**整体旋转 90° 显示**，把手机横过来放就是正的
  - **竖屏**：强制竖屏排版；在横着放的车机/平板上也能转正
  - 横屏不是把竖屏拉伸，而是换成 4 列并排布局：**左列 CPU 通栏（圆环 + 每核柱条），右列进程 TOP 通栏，中间两列是 GPU / 内存 / 磁盘 / 网络四个卡片，趋势图横跨底部**——一屏之内全部显示，不需要滚动
- **分页**：三页，**只能左右滑动翻页，页面上没有任何按钮**
  - **第 1 页「系统」**：CPU 圆环与每核柱条、GPU、内存、磁盘、网络、120 秒趋势、进程 TOP（原版七板块）
  - **第 2 页「游戏」**：帧率、显存与频率
  - **第 3 页「生活」**：天气、电池、系统信息
  - 翻页时底部会短暂浮出「第 2 页 · 游戏性能」，1.4 秒后自己消失
  - **不自动翻页**；横屏被旋转时按内容方向判断，不会滑反
  - 当前停在哪一页会记住
- **皮肤**：右上角 `◐` 按钮打开皮肤面板，五款一键切换，选择会记住：
  | 皮肤 | 风格 |
  |---|---|
  | 深空 | 默认款，近黑底 + 青/绿/琥珀，克制耐看 |
  | 赛博 | 品红霓虹 + 电子紫，品红网格底纹、数字发光 |
  | 全息 | 单色荧光绿终端，等宽字体 + CRT 扫描线 |
  | 极光 | 青绿到靛蓝的冷调渐变，玻璃感卡片 |
  | 熔岩 | 橙红暖调，卡片带暗红辉光 |
- **屏幕常亮**：设置 → 显示 → 休眠 → 选「永不」；或开发者选项里打开「充电时保持唤醒」
- **全屏**：看板右上角有 ⛶ 按钮；也可以把网页「添加到主屏幕」，之后像个 App 一样全屏打开
- **旧手机建议**：插着充电器、亮度调到 30% 左右
- 如果手机上想更彻底（开机自启浏览器、锁屏常亮、防误触），可以再装一个「Fully Kiosk Browser」这类单页浏览器

## 三、文件说明

```
手机监控电脑性能看板/
├─ 启动看板.bat          ← 启动（会结束旧实例，再拉起新实例并打开浏览器）
├─ 停止看板.bat          ← 停止后台服务
├─ 允许手机访问.bat      ← 添加防火墙规则（需要 UAC，一次即可）
├─ 安装开机自启.bat      ← 在「启动」文件夹创建快捷方式
├─ 移除开机自启.bat      ← 取消开机自启
├─ qr.png / qr.svg       ← 手机扫码直达的二维码
├─ address.txt           ← 当前的访问地址（服务启动时自动更新）
├─ server.py             ← 采集 + HTTP 服务（Python 标准库 + psutil）
├─ web/index.html        ← 手机端看板页面（单文件，无 CDN 依赖）
├─ autostart.vbs         ← 静默启动器（开机自启调用它，不弹黑窗）
├─ scripts/              ← 上面那些 .bat 的具体实现
├─ libs/                 ← psutil（本地依赖，不污染系统 Python）
├─ logs/server.log       ← 运行日志，出问题时先看这里
└─ tools/                ← 自检脚本、二维码生成脚本
```

## 四、数据是怎么来的

| 指标 | 来源 | 是否需要管理员 |
|---|---|---|
| CPU 占用 / 每核 / 线程数 | psutil（Windows 系统计数器） | 否 |
| 内存 / 交换分区 | psutil | 否 |
| 显卡占用 / 温度 / 显存 / 功耗 / 频率 | NVML（驱动自带 `nvml.dll`，无子进程） | 否 |
| 磁盘容量 / 读写速度 | psutil | 否 |
| 网络上下行 | psutil（自动识别主网卡） | 否 |
| 进程 TOP | 一次内核查询（`fastproc.py`） | 否 |
| 电池电量 / 充电状态 | psutil | 否 |
| 天气 | [open-meteo](https://open-meteo.com/)（免费、无需 key），IP 粗定位所在城市 | 否 |
| **帧率 FPS** | RTSS 共享内存（需装 MSI Afterburner / RivaTuner） | 否 |

帧率显示 `—` 是正常的：Windows 没有全局帧率接口，需要 RTSS 这类工具提供。

### 补上游戏帧率（一键脚本）

看板里 **帧率** 默认显示 `—`，因为 Windows 本身不提供这个接口。

**`启用帧率FPS.bat`**
1. 双击运行 → 浏览器打开 MSI Afterburner 官方下载页（MSI 禁止程序自动下载，只能手动下）
2. 安装时**务必勾选 RivaTuner Statistics Server**
3. 让 RTSS 常驻后台（托盘粉色小图标），脚本会自动检测到并提示接通
4. 进游戏后看板第 2 页就会显示 FPS

> 帧率不是系统接口，只能由 RTSS 这类工具写进共享内存，看板从那里读取。

不需要的话忽略即可，其它指标都能正常用。

## 五、一键加速

看板右上角有个 **`⚡加速`** 按钮，点一下会整理本机各进程的内存工作集，把闲置内存页推回系统备用列表，立刻释放物理内存。

- **它做什么**：对每个占用超过 40MB 的用户进程调用 Windows 的 `SetProcessWorkingSetSize(-1,-1)`，也就是加速器软件通用的「内存整理」
- **它不做什么**：不结束任何进程、不关任何窗口，不会丢数据
- **安全边界**：跳过系统关键进程（`csrss` / `lsass` / `dwm` / `svchost` 等）；非管理员权限跨不过别的用户；自己这个服务也跳过
- **节流**：两次之间至少 15 秒，按钮上会显示倒计时
- **效果**：通常释放几百 MB 到 1 GB；如果提示「内存已经很干净了」，说明当前没什么可回收的
- **权限**：普通权限即可，不需要管理员

> 注意：它做的是「整理内存」，不是「关闭软件」。想真正腾出大量内存，还是得关掉开着的大程序——这个看板能看到是谁在占（进程 TOP / 内存占用）。

**安全设计**：加速是整个看板里唯一的写操作，所以加了令牌——服务启动时生成随机令牌写进页面，`POST /api/boost` 必须带 `X-Boost-Token` 头，别的网页没法伪造（跨站读不到响应体，也设不了自定义头）。

## 六、常见问题

**手机打不开页面**
1. 手机和电脑是不是连的同一个路由器？（手机别用流量）
2. 第 1 步的 `允许手机访问.bat` 做了吗？Windows 防火墙默认挡掉入站连接
3. 路由器如果开了「AP 隔离 / 访客网络隔离」，两个设备之间也连不通，关掉即可
4. 地址对不对：看 `address.txt`，或重开 `启动看板.bat` 让它更新

**电脑上能看到，手机看不到** → 九成是防火墙；重新双击 `允许手机访问.bat`。

**端口 8787 被别的软件占了** → 服务会自动顺延到 8788/8789…，`address.txt` 里的地址总是当前真实地址。

**想让数据更全（多盘、更多进程）** → 现在这个实例如果是从 DSH 沙箱里启动的，进程列表只能看到一小部分；双击一次 `启动看板.bat` 从桌面启动即可恢复正常。

**想彻底卸载** → 双击 `移除开机自启.bat`，然后删掉整个 `phone-monitor` 文件夹。

## 七、参考过的同类开源项目

挑方案时看过的几个（本项目最终没用它们，但都值得一看）：

- [Pitikapp](https://github.com/Pitikapp/pitikapp) —— 老手机变身 PC 副屏/监控的成熟方案：Android App + PC 端服务，可视化拖拽做仪表盘，还能当 Stream Deck 用
- [PcHWmonitor](https://github.com/Xeakaes/PcHWmonitor) —— 单文件 Windows 服务端（内嵌 LibreHardwareMonitor）+ Jetpack Compose 安卓端，走局域网推送
- [PixelDeck](https://github.com/danishayman/PixelDeck) —— 把旧手机做成像素风桌面看板（时钟/PC 状态/天气），走 USB
- [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) —— 开源硬件传感器读取工具（本项目早期用它补过 CPU 温度，现已移除）

**为什么没直接用 App 方案**：那些都要在手机上装 APK、在电脑上装服务、再做配对，链路长、出问题难排查；而这个方案手机端零安装，打开浏览器就能看，电脑端只有一个 Python 进程，所有数据接口都能用 `curl` 直接验证。

## 八、进阶

- 改端口：`python server.py --port 9000`，然后同步改 `.bat` 里的 8787
- 改刷新频率：`web/index.html` 里 `setTimeout(loop, 1000)`
- 二次开发接口：`GET /api/stats` 返回全部指标 JSON；`GET /health` 带采样时间戳；`POST /api/boost`（需 `X-Boost-Token` 头，值在页面 `<meta name="boost-token">` 里）触发一次内存整理
- 自检：`python tools/check.py`（页面 id 引用、标签闭合、JS 语法）；`node tools/test_orient.js`（横竖屏判定）；`node tools/test_chart.js`（趋势图画布尺寸，防止旋转后模糊）
